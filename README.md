# MinisSkills

Reusable skills for [Open Minis](https://openminis.app/) / Minis agent workflows.

## Skills

| Skill | Description |
|---|---|
| [`image-generator`](./image-generator/) | Generate, test, and refine images from prompts. Includes provider fallback notes, OpenAI-compatible image invocation patterns, WisArt endpoint notes, and local Pillow procedural fallback. |

## Install

Copy a skill directory into your Minis skills folder:

```text
/var/minis/skills/<skill-name>/
```

Each skill follows the `SKILL.md` convention.
