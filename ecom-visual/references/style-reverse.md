# 参考图反推：从「像不像」到「能不能用」

当下游需要复刻某种视觉风格（竞品主图、爆款详情页、某品牌画册）时，先反推参考图，再转成可执行的 Style Lock。

方法借自 `LunarXuan/image-prompt-reverse`（GPL-3.0），只取其中两条硬约束：**内容与画风解耦**、**画风锚点前置**；不采用它的双语长文案与 450–700 字长度——对批量生产是负担。

---

## 一、先问：这张参考图值不值得反推

| 判断 | 处理 |
|---|---|
| 构图、光线、质感确有可取处 | 反推 → 转 Style Lock |
| 只是「卖得好」但画面平庸 | 跳过。学它的**信息结构**（卖点顺序、图标密度），不学画风 |
| 主体是你的同类竞品且高度雷同 | 只取风格不取构图，避免产品图撞脸 |
| 品牌 logo / IP 角色是画面核心 | 不反推。按 `SKILL.md` 红线，不复刻受保护形象 |

---

## 二、内容骨架 / 画风指纹 解耦

分两份清单，**互不混写**。

### 内容骨架（只回答「画了什么、在哪里」）

- 主体是什么、外观、朝向、占比
- 道具、辅助元素
- 场景、背景结构
- 构图位置：左/中/右，谁最靠近镜头
- 前中后景的遮挡与尺度

**禁止出现风格词**——不用「高级」「干净」「治愈」「质感到位」。

### 画风指纹（只回答「怎样被拍出来 / 画出」）

十维，有证据才填，不要求全覆盖：

1. **媒介与渲染方式**：实拍 / 3D 渲染 / 插画 / 拼贴 / 混合，写实程度
2. **线条系统**（插画）：有无外轮廓、粗细变化、闭合或断续、边缘锋利或毛糙
3. **形状语言**：圆润或锋利、几何化或有机构成、比例夸张与简化方式
4. **明暗塑形**：硬光单影 / 柔光渐变 / 多级赛璐璐阴影 / 厚涂塑形
5. **色彩语法**：主辅点缀的面积与位置、冷暖分配、明度层级、饱和度、冷暖对比
6. **笔触与肌理**：可见笔触方向、纸张颗粒、噪点、哑光或镜面
7. **细节分配**：细节集中在哪，哪些被大幅简化
8. **光影**：主光方向、光比、轮廓光、反射落点、氛围处理
9. **构图节奏**：留白比例、裁切方式、视觉重心、重复形状的疏密
10. **后期特征**：颗粒、柔焦、色差、锐化、褪色、商业精修程度

### 内容泄漏检查（关键一步）

把画面里的**人物、物体、服装、地点、动作、专有名称全部抽掉**，剩下的描述还成不成立？

- 成立，并且仍能定义一种连贯的做法 → 它是真画风指纹
- 抽掉内容后只剩「明亮」「干净」「有质感」→ 那是内容复述，退回内容骨架或直接删掉

大多数反推失败都卡在这里：把「画了什么」当成了「怎么画的」。

---

## 三、转成 Style Lock（十项映射）

反推出来的画风指纹，逐项落到 `SKILL.md` 的 Campaign Style Lock 字段上：

| Style Lock 字段 | 从指纹的哪一维来 | 必须补成什么形态 |
|---|---|---|
| 视觉方向 | 媒介 + 渲染方式 | 一句话命名，如 `clean cold-studio skincare` |
| 固定色板 | 色彩语法 | **hex**。参考图取色或近似，不许写「米白」 |
| 冷暖调 | 色彩语法 | warm / cool / neutral，加色温数值如 5500K |
| 字体系统 | 内容骨架（文字区域） | 字体风格 + 字号层级 |
| 背景系统 | 背景结构 + 光影 | 材质 + hex + 有无渐变 |
| 光线系统 | 光影 | 主光方向 + 软硬 + 光比 |
| 布局系统 | 构图节奏 | 留白百分比 + 分栏 + 标签形状 |
| 图标系统 | 细节分配 | 线宽 + 颜色 + 复杂度 |
| 产品呈现规则 | 内容骨架 | 占比百分比 + 角度 + 是否居中 |
| 禁止漂移项 | 后期特征反写 | 禁用项清单 |

**铁律照旧**：反推来的一切形容词都要落成数字或 hex。参考图说「留白很多」不行，得量出来是 45% 还是 60%。

### 量化三件套

反推时顺手量，别靠感觉：

1. **占比**：主体在画面里的高度或面积百分比（可用 Pillow 粗测明暗边界）
2. **留白**：主体外接矩形之外、无遮挡的区域占比
3. **主色**：取 3–5 个色簇的 hex（`references/style-reverse.md` 见下方脚本用法）

```sh
# 粗取主色 + 画面构图比例
python3 /var/minis/skills/ecom-visual/scripts/analyze_ref.py \
  --image /var/minis/attachments/参考图.jpg --colors 5
```

输出供参考的色簇 hex 与明暗分布，**不替代人眼判断**——它只解决「我是眯着眼猜的」这个问题。

---

## 四、锚点前置

权重分配（沿用原技能的核心洞察）：

- 前 1/3：**3–5 个视觉锚点**（最影响相似度的构图/光线/材质/色彩关系）
- 中间：主体与细节
- 结尾：媒介边界与否定清单

不要把所有要点铺成平均长度——模型对提示词后段的遵循度会衰减。

---

## 五、媒介边界双向写

正向写清「这是什么」，负向排除「容易混淆的近邻媒介」：

| 参考图媒介 | 正向声明 | 负向排除 |
|---|---|---|
| 实拍产品 | professional product photography | 3D render, illustration, CGI look |
| 写实 3D | photorealistic 3D render, PBR materials | real photo, anime, painterly |
| 半写实 3D / 潮玩 | semi-realistic 3D vinyl figure | photoreal skin, flat vector |
| 二次元插画 | anime illustration, cel shading | photo, 3D render, thick impasto |
| 厚涂插画 | painterly impasto illustration | flat vector, cel shading, photo |
| 扁平矢量 | flat vector illustration, no gradients | photorealistic, 3D volume, real texture |

---

## 六、不编造

参考图上看不出来的，一律不写：

- 焦距、光圈、快门、ISO、相机型号（只写「广角感」「自然透视」「浅景深」这类视觉效果）
- 摄影师、画师、软件名（转写成可观察的技法）
- 8K、高清（写进正向当**期望质量**可以，但不得声称是原图参数）
- 品牌名、IP 名（转写成轮廓、配色、材质、设计语言）

---

## 七、输出：只交可直接用的东西

反推结果**默认不向用户展示分析过程**，直接给：

1. `Campaign Style Lock`（十项齐全，含 hex 与百分比）
2. `Visual Anchors`（3–5 条，前置）
3. `Negative Constraints`（具体禁用项，不套固定词表）
4. 若用户要出图，接 `references/render.md` 的通道

不输出双语的 600 字长文。电商生产要的是能复用的锁，不是一篇看图作文。

---

## 八、闭环

```
参考竞品图
   ↓ 内容骨架 / 画风指纹 解耦（本文第二节）
画风指纹
   ↓ 十项映射 + 量化（本文第三节）
Campaign Style Lock
   ↓ SKILL.md 铁律 + 图片包编排
批量出图
   ↓ 出图后质检
并排比对参考图，漂移就重写锁，不逐张补描述
```
